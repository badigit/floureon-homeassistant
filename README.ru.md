# Hysen / Floureon — Wi-Fi-термостаты для Home Assistant

[English](README.md) | **Русский**

Современная локальная интеграция для **Wi-Fi-термостатов Hysen HY02/HY03**, использующих UDP-протокол Broadlink. Устройства этого семейства продаются под марками **Floureon, Beok (BeOK), Beca / Beca Energy, Decdeal** и другими. Работает по локальной сети, без облака и внешнего аккаунта.

## Совместимость

**Определяющим является протокол, а не бренд или внешний вид.** Интеграция принимает термостаты с **Broadlink device type `0x4EAD`**. Похожая внешне модель, в том числе под одной из перечисленных марок, не обязательно совместима: версии на другом Wi-Fi-протоколе, Zigbee или Tuya могут отличаться.

В других проектах некоторые термостаты **Computherm** (например, E400RF) описываются как устройства на базе Hysen, но **с этой интеграцией они пока не проверены**. Если вы протестировали другую модель, [создайте issue](https://github.com/badigit/floureon-homeassistant/issues) с точной моделью и Broadlink device type.

## Возможности

- Настройка через UI и уникальный ID по MAC-адресу.
- `climate` с автоматическим режимом, ручным нагревом/охлаждением (где поддерживается) и выключением.
- Текущая и целевая температура, состояние нагрева/охлаждения.
- Пресет `away` с запоминанием отдельной уставки.
- Выбор внутреннего или внешнего датчика, схемы расписания и шага температуры.
- Опциональный `switch` для прежнего сценария с Generic Thermostat.
- Общий `DataUpdateCoordinator`, корректная семантика unavailable и diagnostics.
- Автоматический импорт старой YAML-конфигурации.

UDP-операции выполняются асинхронно. Команды и опрос одного устройства сериализованы; транспорт восстанавливается после сетевых ошибок.

## Требования

- Home Assistant **2026.7.0** или новее.
- Постоянный IP-адрес термостата (рекомендуется резервирование через DHCP).
- Совместимый Broadlink device type **`0x4EAD`**.

## Установка

### HACS

1. Откройте HACS, затем **Custom repositories**.
2. Добавьте `https://github.com/badigit/floureon-homeassistant` как **Integration**.
3. Установите **Hysen Thermostat (Broadlink)** и перезапустите Home Assistant.
4. Откройте **Настройки → Устройства и службы → Добавить интеграцию** и найдите **Hysen Thermostat (Broadlink)**.

### Вручную

Скопируйте `custom_components/floureon` в одноимённый каталог конфигурации Home Assistant и перезапустите Core.

## Параметры

При добавлении задаются адрес устройства, UDP-таймаут и тип сущности. Рекомендуемый тип — `climate`. В параметрах записи доступны:

| Параметр | По умолчанию | Диапазон / смысл |
| --- | --- | --- |
| Интервал опроса | 30 с | 10–3600 с |
| Внешний датчик | включён | внешний или внутренний |
| Схема расписания | 0 | `0`: 5+2, `1`: 6+1, `2`: 7 дней |
| Шаг температуры | 0.5 °C | 0.5 или 1.0 °C |
| Охлаждение | выключено | режим `heat_cool` для подходящего контроллера |

Switch-режим дополнительно позволяет выбрать действие при включении и выключении: физическое выключение, min/max или конкретная температура.

## Переход со старой версии

Старые блоки `climate: - platform: floureon` и `switch: - platform: floureon` импортируются в config entry при первом запуске. После успешного появления устройства YAML-блок можно удалить.

`name`, настройки датчика, расписания, точности и switch-режима сохраняются. Старое значение точности 0.1 °C переносится как 0.5 °C: регистр целевой температуры Hysen физически поддерживает только половины градуса.

## Разработка

```bash
uv sync --group dev
uv run pytest
```

Тесты Home Assistant запускаются на Linux: ядро импортирует POSIX-модуль `fcntl`, которого нет на Windows. CI дополнительно запускает hassfest и HACS validation.

## Благодарность

Протокол термостата реализует библиотека [`broadlink-async`](https://github.com/mjg59/broadlink-async). Этот проект является самостоятельной новой интеграцией и не продолжает Git-историю прежнего `hass-floureon`.

## Совместимость с предыдущими установками

Отображаемое имя изменено на **Hysen Thermostat (Broadlink)**, но домен Home Assistant и каталог установки остаются `floureon`. Существующие записи конфигурации и идентификаторы сущностей сохраняются, переустановка не требуется. URL репозитория не менялся.
